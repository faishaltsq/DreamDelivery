# DREAM DELIVERY — ART PACK v0.1 (PROTOTYPE ASSETS)

## Important truth about this pack
This is a **real, file-separated prototype art pack**, built from the user's approved concept reference and generated art sheets. It is NOT yet a fully approved, independently rendered, high-resolution commercial art library.

It contains **234 asset entries** (plus reference images, manifests, examples, instructions, and a preview). File counts include reference-derived crops and UI SVG vectors. Some source panel artwork is small and has been upscaled only to help preview.

### Quality categories
- `vector-ready`: scalable SVG UI components designed specifically for the prototype.
- `prototype-extracted`: separated visual elements from generated concept sheets, suitable for mockup and vertical-slice testing.
- `cutout-needs-qa`: cutouts with transparent background generated by thresholding cream background; visually inspect edges.
- `placeholder-animation`: structurally valid animation atlases with pose reuse / one-pixel movement; **not polished unique animation frames**.
- `prototype-upscaled`: large screenshot preview generated by resampling a smaller painting; **not a native 1600x900 painting**.
- `synthetic-prototype-sfx`: procedural sound placeholders.

## How to use with coding agent
1. Copy `assets/` to your public/static assets or add to your asset build pipeline.
2. Read `data/asset-content-manifest.json` for route, courier and token mapping.
3. Show `preview/index.html` to align the visual direction.
4. Load courier horizontal PNG sprite atlas per `animations.json`: 64x64 cells, frame count 4, pixelated rendering.
5. Compose interface using **real HTML** and the SVG components; no text baked into screenshot mocks.
6. In dev, select Momo + Moonfield vertical slice before expanding.

## Missing for production-perfect quality
- Full-resolution independent hero and environments with corrected perspective and multi-layer parallax art.
- Hand-registered professional sprite animations (8-direction turns if needed).
- QA on character cutout boundaries and artistic fidelity to the approved master.
- Real licensed soundscapes, accessible iconography, localization, and user-generated content safety.
- Device testing for mobile and desktop; Steam store assets only after separate requirements validation.

## Rights and source
All concept illustrations in this ZIP originate from user-provided / conversation-generated art; SVG vectors and tone placeholders were produced here. Verify licensing of external fonts/tools and applicable store/content policies separately. No font binaries included.

## Folder structure
- `references/`: approved reference and production sheets (do not use as whole-screen interfaces)
- `assets/environments/`: world backgrounds and concept strips
- `assets/couriers/`: sprites, poses, portraits, animation metadata
- `assets/ui/`: scalable design components and theme tokens
- `assets/icons`, `assets/stamps`, `assets/relics`, `assets/events`, `assets/mail`, `assets/effects`, `assets/props`, `assets/postcards`
- `assets/audio/prototype`: optional toy feedback tones
- `data/`: inventory and data-driven asset mapping
- `docs/`: original plan and outstanding production backlog
- `preview/`: self-contained offline preview

## Additions after initial extraction
- `assets/marketing/`: marketing reference images for icon, Steam capsule, social preview and vertical art. These are **not store-size finals**.
- `assets/events/banners/`: seasonal storyboards with some embedded artwork text, use as visual references.
- `assets/environments/*/scene-wide-alt.png`: wide route composition options derived from the latest generation.
- `assets/concept-extras/`: tile, prop, effect and NPC contact sheets that require independent asset finishing.

### Asset production status
Deliverable is a **first integrated prototype art pack**, not a 100% shippable full-resolution commercial art pack. Production gaps remain and are explicitly labeled.
